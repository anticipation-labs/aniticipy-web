# Anticipy — website

The Next.js application behind **https://www.anticipy.ai**: the marketing site,
pre-orders, the waitlist, the `/engine` demo, the CRM, and HQ's front door.

Split out of `anticipation-labs/Anticipy`, which held two unrelated products in
one tree. The pendant system — the brain worker, the PocketBase backend, the
Chrome extension, the iOS and macOS apps, the firmware — stays there. This repo
is only the website.

## Running it

```bash
npm install
npm run dev        # http://localhost:3000
npx tsc --noEmit   # there is no ESLint config; `npm run lint` opens a setup prompt
npx playwright test
```

The build needs Supabase credentials in `.env.local`, or `next build` fails
while prerendering `/admin/offers`:

```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
```

## Layout

| Path | What it is |
|---|---|
| `src/app/` | 62 pages, 94 API routes (App Router) |
| `src/lib/`, `src/components/` | shared code and UI; `@/*` maps to `./src/*` |
| `public/` | images, video, downloads |
| `supabase/` | SQL schema for the ~40 tables the site reads |
| `tests/` | Playwright specs (`playwright.config.ts` points here) |
| `__tests__/` | one node test |
| `docs/` | product and architecture notes |
| `state/builds/manifest.json` | the Mac DMG's sha256 and build commit |

That last one looks out of place and is not: `src/lib/release-meta.ts` imports
it directly, so `/api/app/state` and the download page cannot build without it.
It is the only file kept from the old repo's 1,797 MB `state/` directory.

## What was deliberately left behind

Nothing here is lost — it is all still in `anticipation-labs/Anticipy`.

| Left behind | Why |
|---|---|
| `engine/`, `desktop/`, `installer/`, `executor/`, `native_host/`, `extension_v4/` | The local Action Engine and Mac app. A separate product; nothing in `src/` imports them. |
| `firmware/` | The pendant. Belongs with the pendant system. |
| `.github/workflows/windows-build.yml` | Builds the Python engine with PyInstaller, not this site. This repo needs its own CI. |
| `state/` (all but the manifest), `proof-artifacts/`, `.anticipy/` | 1,836 MB of run artifacts. Regenerated by the scripts that write them. |
| `scripts/`, `tools/`, `contracts/`, `research/`, `verifier/` | Engine harness and research. `package.json` references none of it. |
| `planning/`, `tasks/`, `roles/`, `_archive/`, `archive/`, `dist/`, `output_files/` | Process and scratch material. |
| ~46 root `*.png`, ~20 root status `*.md` | Screenshots and dated status notes. Several `vercel-env-*.png` appear to be screenshots of an environment-variable dashboard and should be reviewed for secrets before being reused anywhere. |

Verified before the split: with exactly the files in this repo, `next build`
compiles and prerenders all 91 static pages.

## History

This starts fresh rather than carrying the old repo's history, for two reasons.
That history is ~2.1 GB, almost all of it the `state/` artifacts above. And it
contains committed credentials — a live Cerebras API key in
`planning/00-handoff/BUG_LIST.md` and a production access code in several files
— which a `git clone` of a **public** repo hands to anyone. Those still need
rotating in the old repo; not inheriting them here is separate from fixing them
there.

The full history remains in `anticipation-labs/Anticipy`.
